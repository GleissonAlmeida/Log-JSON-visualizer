========================================================================
   LOGPLOTTER EM LINGUAGEM C - PACOTE EXECUTÁVEL PARA WINDOWS 11 (64-BIT)
========================================================================

Este pacote contém o executável binário compilado nativamente para Windows 11 / Windows 10 (x86-64),
sem necessidade de instalar nenhum compilador, Python ou Node.js.

CONTEÚDO DO PACOTE:
--------------------
1. log_plotter.exe         - Binário executável nativo em C99 (64-bit).
2. sample_iot.json         - Exemplo de log de dados em formato JSON com telemetria.
3. executar_no_windows.bat - Script de 2 cliques para rodar e abrir o gráfico automaticamente.
4. LEIA-ME_WINDOWS.txt     - Este arquivo com as instruções de uso.

COMO USAR NO WINDOWS 11:
------------------------
Opção A (Mais fácil - 2 cliques):
  - Dê um duplo clique no arquivo 'executar_no_windows.bat'.
  - O terminal do Windows abrirá, processará o log, exibirá a tabela de
    estatísticas e o gráfico ASCII, e abrirá o arquivo 'grafico_c.html'
    no Microsoft Edge ou no seu navegador padrão.

Opção B (Linha de comando / CMD / PowerShell / Windows Terminal):
  Abra o prompt na pasta do programa e execute:

  # 1. Execução básica:
  .\log_plotter.exe sample_iot.json

  # 2. Especificando o campo do Eixo X e as métricas desejadas:
  .\log_plotter.exe sample_iot.json -x timestamp -m temperatura,umidade,pressao_hpa

  # 3. Gerando o gráfico interativo Chart.js:
  .\log_plotter.exe sample_iot.json --html meu_grafico.html
  start meu_grafico.html

PARÂMETROS SUPORTADOS:
----------------------
  -i <arquivo.json>     : Caminho do arquivo de log em formato JSON
  -x <campo_x>          : Nome do campo para o Eixo X (ex: timestamp, horario, id)
  -m <campo1,campo2>    : Lista separada por vírgula das métricas para o Eixo Y
  --html <arquivo.html> : Gera arquivo HTML interativo com Chart.js
  --gnuplot             : Gera script e dados para plotagem com Gnuplot
  --no-ascii            : Desativa a renderização do gráfico ASCII no terminal
