========================================================================
   LOGPLOTTER EM LINGUAGEM C (v2.5) - PACOTE EXECUTÁVEL PARA WINDOWS 11
========================================================================

Este pacote contém o executável binário compilado nativamente para Windows 11 / Windows 10 (x86-64),
estaticamente vinculado (-static), sem necessidade de instalar DLLs externas, compilador, Python ou Node.js.

NOVIDADES DA VERSÃO 2.5:
-------------------------
1. [NOVO] Suporte Completo à Leitura de Arquivos CSV (.csv):
   - Lê arquivos CSV com detecção automática de separadores (vírgula ',', ponto-e-vírgula ';' e tabulação '\t').
   - Suporta números decimais com vírgula (padrão brasileiro/europeu, ex: 12,50).
   - O executável C aceita arquivos .csv diretamente pela linha de comando ou arrastando o arquivo para cima do .exe.
2. Exportação para PNG com Cursor e Valores das Amostras:
   - Ao salvar o gráfico em imagem PNG com o cursor ativo, a imagem gerada inclui a linha vertical tracejada, a etiqueta da amostra no topo, os pontos marcadores em cada curva e o cartão flutuante de inspeção.
3. Hold de Telemetria (Sample & Hold) no Cursor e HUD:
   - Mantém o último valor válido recebido para sinais esparsos de CAN bus, exibindo o status [hold].
4. Espaço Dedicado entre a Legenda dos Sinais e o Gráfico:
   - Margem de respiro de 36px abaixo da legenda dos sinais, eliminando qualquer sobreposição com o cursor.
5. Cursor Eixo X Totalmente Reativo com Navegação por Mouse e Teclado.

CONTEÚDO DO PACOTE:
--------------------
1. log_plotter.exe         - Binário executável nativo em C99 (64-bit Windows com suporte a CSV e JSON).
2. sample_can_bus.csv      - Log CAN Bus em formato CSV real (1450 amostras).
3. sample_can_bus.json     - Log CAN Bus automotivo em formato JSON Lines.
4. sample_iot.json         - Exemplo de telemetria IoT convencional.
5. grafico_c.html          - Gráfico interativo completo gerado pelo executável em C.
6. executar_no_windows.bat - Script de 2 cliques para rodar e abrir o gráfico automaticamente.
7. LEIA-ME_WINDOWS.txt     - Este arquivo com as instruções de uso.

COMO USAR NO WINDOWS 11:
------------------------
Opção A (Mais fácil - 2 cliques):
  - Dê um duplo clique no arquivo 'executar_no_windows.bat'.
  - O terminal do Windows abrirá, processará o log, exibirá a tabela de
    estatísticas detalhada e abrirá o arquivo 'grafico_c.html'
    no Microsoft Edge ou no seu navegador padrão.

Opção B (Arrastar e soltar):
  - Arraste qualquer arquivo .json (ex: sample_can_bus.json ou seu log CAN)
    diretamente para cima do ícone do 'log_plotter.exe'.

Opção C (Linha de comando / CMD / PowerShell / Windows Terminal):
  Abra o prompt na pasta do programa e execute:

  # 1. Processar log CAN Bus:
  .\log_plotter.exe sample_can_bus.json --html grafico_c.html

  # 2. Executar diretamente sem parâmetros (auto-detecta sample_can_bus.json):
  .\log_plotter.exe

  # 3. Especificando o campo do Eixo X e as métricas desejadas:
  .\log_plotter.exe sample_can_bus.json -x # -m BrakeSwitch,WheelBasedVehicleSpeed,curr_gear,sel_gear

  # 4. Abrir o gráfico gerado no navegador:
  start grafico_c.html
