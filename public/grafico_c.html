Documentação e Guia de Uso

LogPlotter v2.5 (C99 + Chart.js) é uma ferramenta profissional de alta performance para visualização de logs técnicos de telemetria.

  • Eixos Múltiplos (Y, Y1, Y2): atribua cada sinal individualmente a um eixo dedicado através dos botões segmentados [Y] [Y1] [Y2].
  • Cursor Vertical do Eixo X: passe o mouse para inspecionar amostras a 60 FPS com interpolação contínua; use as setas do teclado ou clique para fixar o cursor.
  • Sample & Hold: telemetria esparsa mantém o último valor transmitido preenchendo lacunas sem descontinuidades abruptas.
  • Exportação em PNG HD: o botão Salvar PNG gera imagem com fundo escuro profissional, linha de cursor e cartão flutuante de inspeção.
